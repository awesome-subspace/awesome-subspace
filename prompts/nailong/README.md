# 奶龙（Nailong）抽象 AI 视频 Prompt 专区

奶龙是目前中文互联网最热门的 Meme 角色之一。本目录专门收集以奶龙为主角的 AI 视频生成提示词。

## 角色说明

**奶龙**：黄色圆滚滚3D卡通小恐龙，绿色大眼睛，奶白色肚皮，短手短脚，表情呆萌。

## 重要：参考图要求

> 大多数 AI 视频模型（Seedance、即梦、可灵、Vidu 等）**并不能仅凭名字稳定还原奶龙形象**。  
> **强烈建议上传奶龙参考图**，并在提示词中注明"角色与参考图一致"。

推荐工作流：
1. 准备奶龙高清参考图（正面、侧面各一张效果更佳）
2. 上传至对应平台的"角色参考"或"图生视频"入口
3. 在 Prompt 中加入描述锁定角色外形（见各 Prompt 中的 `character_lock` 字段）
4. 用平台的主体一致性功能保持角色跨镜头稳定

## 收录标准

- 提示词须包含奶龙的外形描述或注明参考图要求

- 欢迎补充实际生成效果截图或视频链接
