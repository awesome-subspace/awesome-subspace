# 提示词模板

## 标题（简洁描述主题）

**分类：** `cyber` / `nature` / `daily` / `cosmos` / `classical` / `chaos`

**标签：** `意象1` `意象2` `意象3`

**提示词：**

```
在这里粘贴你的提示词内容。
支持中文、英文或双语。
```

**中文版（可选）：**

```
如果主提示词是英文，可以在这里提供中文翻译或中文版本。
```

**推荐工具：** Sora / Runway / Kling / 即梦 / Vidu（填写你测试过的工具）

**效果描述：** 简单描述用这个提示词能生成什么样的视频效果（1-2句话）。

**贡献者：** @你的GitHub用户名
