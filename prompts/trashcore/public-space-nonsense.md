# 公共空间迷惑行为

**分类：** `trashcore`

**标签：** `公共空间` `集体沉默` `日常错位` `一本正经`

**推荐工具：** 即梦、Kling、Sora

> 统一风格：路人手机纪实，轻微手抖，自动对焦反复拉风箱，自然环境音，无人解释异常，表演越严肃越好。

## 01. 地铁到站是客厅

```
早高峰地铁进站，车门打开后里面是一间普通家庭客厅，奶奶坐沙发看电视。乘客自然走进去找位置，奶奶把遥控器递给站务员，车门关闭后客厅平稳驶离。
```

## 02. 红绿灯犹豫

```
十字路口红绿灯在红色和绿色之间快速犹豫，行人与车辆同步前进一步退一步。黄灯忽然从灯箱里走下来亲自指挥交通，路口立刻恢复秩序。
```

## 03. 广场喷泉请假

```
城市广场喷泉按时响起音乐，所有喷头却只喷出一张张请假条。游客认真阅读后点头离开，保洁员拿来一杯水倒进池中，喷泉立刻恢复并对他鞠躬。
```

## 04. 公交站搬家

```
十几个人在公交站安静等车，公交站牌突然长出轮子沿马路开走。所有人一边看手机一边整齐跟随，真正的公交车在后面缓慢追赶他们。
```

## 05. 商场扶梯选择人生

```
商场两部扶梯，一部写“上楼”，另一部写“差不多得了”。顾客全部选择第二部，扶梯把他们送回原地，每个人满意地点头，再次排队乘坐。
```

## 06. 公园长椅排队

```
公园里几十张长椅整齐排队等待一位老人坐下。老人逐张检查，最后坐在地上，所有长椅同时松了一口气并四散离开。
```

## 07. 斑马线脱落

```
行人准备过马路，斑马线白条突然像胶带一样从地面卷起，整齐滚到路边。人群停住，掏出粉笔在地上临时画了一架钢琴，踩着琴键声音过街。
```

## 08. 商场模特下班

```
晚上十点商场关门，橱窗模特依次取下自己的塑料头，夹在腋下排队打卡。最后一名真人店员站进橱窗保持不动，保安经过给他整理了一下衣领。
```

## 09. 广播寻找广播

```
火车站广播反复播报“请广播尽快前往服务台”。天花板上的喇叭一个个脱落，长出细腿奔向服务台，旅客抬头看一眼，继续低头吃泡面。
```

## 10. 广场影子迟到

```
正午广场上的每个人都没有影子，五分钟后，大量影子从地铁口冲出来寻找主人。影子们站错位置又不断交换，最后一根路灯领走了所有剩余影子。
```
