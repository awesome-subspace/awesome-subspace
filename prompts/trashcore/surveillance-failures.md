# 监控录像事故

**分类：** `trashcore`

**标签：** `监控` `低清` `错误物理` `无人值守`

**推荐工具：** 即梦、Kling、Vidu

> 统一风格：固定 CCTV 鱼眼镜头，右上角错误时间戳，12fps，过度压缩，冷白灯频闪，无配乐。

## 01. 自动门面试

```
凌晨两点的空商场，一扇自动门反复打开关闭，门外没有人。几分钟后，一把塑料椅子自己滑到门前，门立刻停止工作，椅子停顿三秒，又慢慢滑走。
```

## 02. 电梯吐盆栽

```
办公楼电梯监控，电梯门每次打开都会多推出一盆绿植，保安不断把盆栽搬回去。第十次开门时，电梯里只站着第一盆绿植，戴着保安帽。
```

## 03. 便利店冰柜逃跑

```
深夜便利店监控，一台冰柜以每分钟十厘米的速度向出口移动，店员低头玩手机完全没有发现。冰柜终于挪出门外，店员抬头，把门口的“营业中”牌子翻成“休息中”。
```

## 04. 购物车开会

```
地下停车场固定镜头，七辆购物车从不同方向缓慢滑来，围成一个标准圆圈静止十秒，随后同时倒车离开，只有一辆车因为轮子卡住留在原地。
```

## 05. 雨伞迟到

```
写字楼大堂监控，人群冒雨进门，每个人都没有打伞。最后一把打开的黑伞独自飘进大堂，追着人群进入电梯，电梯超载警报立刻响起。
```

## 06. 保安亭复制

```
小区门口监控，保安走出保安亭巡逻，回来时旁边多出一座一模一样的保安亭。他犹豫后走进新亭，旧亭里的另一个他拉下百叶窗。
```

## 07. 地垫执法

```
超市入口的迎宾地垫突然竖起来，阻止每个顾客进入。顾客依次出示购物袋、会员卡和一根葱，地垫才侧身放行，最后它自己走进超市购物。
```

## 08. 打印机越狱

```
无人办公室夜间监控，打印机连续吐出写着“马上回来”的白纸，纸张在地面排成一条路。打印机沿着纸路缓慢滑出画面，第二天员工只给空桌加了一包新纸。
```

## 09. 快递柜点名

```
小区快递柜监控，所有柜门按顺序打开又关闭，像在点名。最后一个柜门打开后，一只空纸箱走出来，对镜头鞠躬，柜门集体闪绿灯鼓掌。
```

## 10. 时间戳下班

```
空仓库监控画面，场景完全静止，只有右上角时间戳突然从屏幕上掉下来，像实体数字一样摔在地上。清洁工进来扫走数字，画面从此停在 18:00:00。
```
