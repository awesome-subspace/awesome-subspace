# 乡镇舞台奇观

**分类：** `trashcore`

**标签：** `舞台` `庆典` `塑料花` `尴尬演出`

**推荐工具：** 即梦、Vidu、Kling

> 统一风格：临时搭建舞台，红色地毯，塑料花，褪色横幅，正午硬光，手机竖屏拍摄，音响偶尔啸叫。

## 01. 剪彩无限延长

```
十二位嘉宾站在临时舞台上剪彩，红绸被剪断后立刻长出更长一截。大家继续微笑剪彩，红绸越剪越多，最终淹没舞台，只剩横幅写着“圆满结束”。
```

## 02. 气球拱门辞职

```
开业庆典主持人刚喊倒计时，气球拱门自己拔起两条支架，像双腿一样走下舞台。所有嘉宾假装没看见，对着空门框继续合影。
```

## 03. 广场舞掉帧

```
十六位阿姨整齐跳广场舞，每隔三秒所有人瞬间换到下一个动作，中间动作完全消失，像现实掉帧。只有音箱以丝滑动作在队伍中央领舞。
```

## 04. 主持人回声实体化

```
主持人说“欢迎大家”，舞台后方走出一个半透明的主持人重复这句话；每次回声都变成新的主持人。几十个主持人挤满舞台，真正的主持人悄悄坐到观众席嗑瓜子。
```

## 05. 狮子不想醒

```
开业舞狮表演开始，锣鼓震天，红色狮子始终趴在地毯上不动。两名表演者从狮子服里出来吃盒饭，狮子服却突然独自起身完成一套高难度动作。
```

## 06. 横幅现场改口

```
村口舞台正在举行热闹庆典，背景横幅上的字每隔两秒自动变化，从“隆重开幕”变成“差不多行了”，最后变成“大家早点回家”，演员仍然满脸笑容继续表演。
```

## 07. 塑料花结果

```
舞台边一排廉价塑料花在歌手唱到最高音时突然结出西红柿。观众安静排队采摘，歌手降低音量，改唱当天西红柿价格。
```

## 08. 颁奖礼奖杯逃跑

```
获奖者伸手接奖杯，金色塑料奖杯长出两条细腿绕舞台逃跑。主持人与获奖者保持职业微笑追逐三圈，最后把话筒颁给获奖者，奖杯在台下鼓掌。
```

## 09. 音响主持全场

```
主持人话筒没有声音，旁边老旧音响却用主持人的声音宣布节目。主持人无奈退场，音响开始报幕、唱歌、讲笑话，最后自己播放掌声并鞠躬。
```

## 10. 合影不断加宽

```
庆典结束集体合影，每次摄影师喊“往中间靠”，舞台就向两边自动加宽一米，人群反而越来越分散。镜头最终拉到极远，所有人像一条细线，摄影师说“完美”。
```
