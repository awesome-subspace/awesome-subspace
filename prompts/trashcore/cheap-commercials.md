# 五毛商业广告

**分类：** `trashcore`

**标签：** `广告` `电视购物` `绿幕` `塑料质感`

**推荐工具：** 即梦、Kling、Sora

> 统一风格：地方电视台深夜广告，4:3 画幅，绿幕抠像白边，过曝棚灯，巨大字幕，廉价音效，频繁硬切。

## 01. 永远切不完的菜刀

```
兴奋主持人展示一把塑料菜刀，轻轻一挥，桌上的黄瓜自动分成两半，桌子也分成两半，演播室背景继续分成两半。主持人对着黑色虚空竖起大拇指，字幕写“锋利但有分寸”。
```

## 02. 反向吸尘器

```
电视购物主持人演示“超强吸尘器”，机器打开后把灰尘、纸屑、沙发和主持人的假发全部喷满房间。主持人在飞舞垃圾中微笑，屏幕打出五星好评和“让家更有生活气息”。
```

## 03. 多功能塑料盆

```
主持人严肃介绍一个九块九包邮的红色塑料盆，快速硬切展示它被当作锅、帽子、方向盘、卫星天线和公司印章使用。最后盆坐在主持人位置上介绍主持人。
```

## 04. 无线电饭煲

```
廉价棚拍广告，一台没有电线的电饭煲在空桌上剧烈抖动。主持人掀开盖子，里面不是米饭而是一台更小的电饭煲，连续打开七层，最里面坐着主持人的微缩版本。
```

## 05. 自动鼓掌手套

```
两只橡胶手套悬在绿幕前自动鼓掌，主持人宣称它能解决所有尴尬场合。切到婚礼、会议、医院走廊和空停车场，手套始终在同一个位置疯狂鼓掌，所有人保持沉默。
```

## 06. 防水纸巾

```
主持人把一张“百分百防水纸巾”放进鱼缸，纸巾完全干燥，鱼缸和水却瞬间湿透并瘫软在桌上。主持人拿纸巾擦鱼缸，鱼缸恢复成立方体，鱼开始鼓掌。
```

## 07. 智能拖鞋导航

```
广告模特穿着会导航的发光塑料拖鞋，拖鞋用机械女声不断说“前方直行”。模特穿过厨房、墙壁、稻田和婚礼现场，最终回到原地，屏幕显示“已节省 0 米”。
```

## 08. 增高矿泉水

```
主持人喝下一口瓶装水，身体没有变化，脚下地板却快速下降两米，于是看起来变高了。全场工作人员热烈鼓掌，字幕写“物理增高，效果看得见”。
```

## 09. 一次性电视

```
主持人从透明塑料袋里取出一台超薄电视，开机画面正是这条广告。广告里的主持人也拆开电视，无限套娃，现实主持人等得不耐烦，直接把电视当湿巾擦桌子。
```

## 10. 静音喇叭

```
主持人声嘶力竭地推销“全新静音大喇叭”，画面完全没有声音，只有彩色爆炸字幕。最后喇叭轻轻亮灯，主持人的嘴被自动打上马赛克，价格从 999 降到 998。
```
