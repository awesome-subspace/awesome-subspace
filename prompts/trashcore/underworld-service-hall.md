# 阴间便民服务大厅

**分类：** `trashcore`

**标签：** `政务大厅` `幽冥办事` `低清纪实` `无效流程`

**推荐工具：** 即梦、Kling、Sora

> 统一风格：县城便民服务大厅实拍，冷白日光灯轻微闪烁，红色 LED 叫号屏，蓝色塑料椅，2011 年廉价安卓手机竖屏画质，自动白平衡反复抽搐，办事员和群众始终严肃，把所有异常当作正常流程。不要电影感，不要精致灯光，不要唯美构图。

## 01. 给影子办暂住证

```
一名男子在窗口给自己的影子办暂住证，影子从脚下揭下来，拿着材料独自排到隔壁窗口。办事员盖章后，影子被压成标准证件照大小，搬进档案柜居住；男子领到一张复印影子，贴在脚边满意离开。
```

## 02. 注销昨天

```
群众递上一张写着“昨天”的皱纸申请注销，办事员核对后把它塞进碎纸机。大厅里所有挂钟同时倒退二十四小时，窗外刚停好的车辆倒着开走，只有叫号屏冷静显示“昨天已注销，请勿重复经历”。
```

## 03. 叫号叫到下辈子

```
红色叫号屏从 A017 缓慢跳到“下辈子 001”，坐在蓝色塑料椅上的群众集体起身，却发现每个人手里的号码都写着“上辈子已过号”。保安推来一台碎纸机，让大家把号码纸塞进去重新投胎取号，所有人立刻安静排队。
```

## 04. 公章无限套娃

```
办事员在申请表上盖下一枚红章，印泥里立刻钻出一个巴掌大的办事员，拿更小的公章继续盖。画面不断特写，桌面很快站满层层缩小的窗口人员；最小的办事员看了一眼微型手表，宣布全大厅午休。
```

## 05. 开具没来过证明

```
窗口要求群众证明自己从没来过，男子当场从监控画面里消失，只剩一把蓝色塑料椅替他排队。办事员认真把“查无此人”证明递给椅子，椅子自动折成一个信封，从大厅门缝里寄了出去。
```

## 06. 自助机打印大厅

```
群众点击自助机上的“打印办事大厅”，机器开始吐出一张无限延伸的彩色大厅照片。排队的人依次走进照片里的窗口继续办理，真实大厅逐渐变空；最后机器打印出同一台自助机，并提醒外面的机器带好复印件。
```

## 07. 排队队伍首尾相连

```
固定广角监控里，窗口前的队伍绕过走廊，从墙后重新接回队首，每个人都在给自己的后背排队。一名群众试图离开，整条队伍像充电线一样跟着他穿过大厅，最终插进叫号屏，屏幕电量变成 1%。
```

## 08. 下班按钮提前下班

```
下午四点五十九分，办事员准备按下“下班”按钮，按钮突然长出两条细腿抢先跑出大厅。所有窗口人员保持职业微笑追赶，桌椅和隔离带也整齐跟跑；叫号屏留在空大厅里独自播报“请工作人员明天再来”。
```

## 09. 意见箱改变天气

```
群众把一张“灯太暗”的意见投入红色意见箱，天花板立刻下起室内小雨。第二张意见写“地面太湿”，雨水瞬间向上流回灯管；办事员撑伞递出满意度评价器，五颗星从屏幕掉下来堵住排水口。
```

## 10. 证件照扣留人脸

```
大厅角落的证件照机器闪光一次，男子的人脸被完整留在白色幕布上，自己的头部只剩缓慢旋转的加载图标。办事员用剪刀把幕布上的脸裁下、塑封、盖章，递给男子说“本人可以不来，脸到了就行”。
```
