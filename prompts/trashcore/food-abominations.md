# 食物邪典现场

**分类：** `trashcore`

**标签：** `食物` `错误烹饪` `巨物` `庄严摆盘`

**推荐工具：** 即梦、Kling、Vidu

> 统一风格：短视频美食教程，过度饱和，顶视镜头，廉价厨房，动作自信但方法完全错误，结尾必须认真试吃。

## 01. 水泥炒饭

```
美食博主把米饭倒进小型水泥搅拌机，加入鸡蛋、葱花和一块红砖，认真搅拌。成品是一座冒热气的迷你居民楼，博主撒上芝麻，用勺子从阳台挖一口试吃并满意点头。
```

## 02. 一根面条

```
厨师拉出一根无限长的面条，面条穿过厨房、街道、城市和云层，始终没有断。镜头回到锅边，厨师看了看手表，把整口锅当作碗端走。
```

## 03. 反向火锅

```
一桌人围着空火锅认真夹菜，筷子每次伸进锅里都会夹出完整生食材，然后放回盘子。桌上的熟菜逐渐全部还原，最后锅底跳回调料袋并自动封口。
```

## 04. 巨型煎蛋

```
街边摊老板敲开普通鸡蛋，蛋液迅速铺满整条马路，车辆在蛋白上缓慢行驶。老板用两把扫帚翻面，折叠成公交卡大小，装进泡沫餐盒递给唯一顾客。
```

## 05. 空气炸空气

```
博主把一个空盘子放进空气炸锅，设置二十分钟。开盖后盘子里出现一团金黄酥脆的空气，咬下去发出巨大咔嚓声，厨房所有窗帘同时被风吹起。
```

## 06. 蛋糕装修队

```
厨师给三层蛋糕裱花，几名微型装修工从奶油袋里走出来，搭脚手架、贴瓷砖、安装窗户。厨师插上蜡烛，蛋糕里的住户集体探头要求关灯。
```

## 07. 拍黄瓜反击

```
厨师举刀准备拍黄瓜，黄瓜抢先弹起，轻轻一拍把菜板压成整齐蒜泥。厨师沉默片刻，把蒜泥装盘，黄瓜戴上厨师帽对镜头介绍下一道菜。
```

## 08. 方便面发布会

```
豪华新品发布会中央罩着一碗泡面，主持人倒数后揭幕，泡面缓慢升空并绕场一周。所有记者疯狂拍照，面饼落回纸碗，字幕庄严宣布“还是原来的味道”。
```

## 09. 馒头充电

```
早餐摊老板把白馒头逐个插上充电线，馒头充满后亮起绿色指示灯，在蒸笼里自动旋转。顾客咬一口，手机电量立刻变成 101%，馒头显示低电量警告。
```

## 10. 西瓜开会

```
十个西瓜围坐餐桌举行严肃会议，中间的人类被切成标准果盘造型但毫发无伤，困惑地转动。西瓜们一致敲桌通过决议，给人类贴上“保甜”标签。
```
