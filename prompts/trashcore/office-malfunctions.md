# 职场系统失控

**分类：** `trashcore`

**标签：** `办公室` `会议` `打印机` `形式主义`

**推荐工具：** Kling、即梦、Sora

> 统一风格：普通写字楼实拍，冷白顶灯，灰色隔断，固定中景，表演一本正经，所有荒诞事件都被当成正常流程。

## 01. 会议桌加载中

```
十二个人严肃开会，会议桌中央出现旋转的加载图标，所有人安静等待。加载到 99% 后桌子突然消失，众人仍把胳膊悬在原位继续记笔记。
```

## 02. PPT 走出屏幕

```
员工讲解季度报表，柱状图从投影幕上长成立体建筑并顶穿天花板。他熟练翻到下一页，一张巨大饼图滚进会议室，所有人低头避让但没人停止鼓掌。
```

## 03. 打卡机审判

```
员工依次刷脸打卡，机器对每个人都机械播报“长得不像本人”。最后一盆绿植经过，机器立刻显示“验证成功，今日最早到岗”，同事们向绿植投去羡慕目光。
```

## 04. 工位漂流

```
办公室地面缓慢变成河流，所有工位像木筏一样顺流移动。员工一边划水一边敲键盘，主管坐在打印机上漂过，提醒大家不要影响下午交付。
```

## 05. 已读自动回复

```
员工电脑不断弹出“收到”，每弹一次，身后就出现一个西装人点头说“收到”。房间很快挤满点头的人，员工发出“别收到了”，所有人齐声回答“收到”。
```

## 06. 团建拔河

```
公司团建在会议室拔河，绳子两端都没有人，员工站成一排认真给绳子加油。绳子独自激烈拉扯，最终从中间打了一个领带结，老板宣布团队凝聚力显著提升。
```

## 07. 电梯汇报

```
员工在电梯里向老板汇报工作，每到一层电梯门打开，外面都是同一间会议室和同一群同事。第十八次开门后，员工走进去，发现电梯已经坐在主位上。
```

## 08. 年终奖缩水

```
老板把一个巨大红包递给员工，员工每说一次谢谢，红包就缩小一半。最后红包变成一粒红色像素，员工小心放进口袋，老板带头热烈鼓掌。
```

## 09. 饮水机晋升

```
晨会宣布新部门经理，镜头缓慢转向角落的饮水机。全体员工依次上前握手祝贺，饮水机冒出一个气泡，秘书认真记录为“重要讲话”。
```

## 10. 下班按钮

```
墙上出现一个写着“下班”的红色按钮，每个人路过都想按但被主管摇头制止。晚上十二点，清洁工按下按钮，整栋办公楼像折叠纸盒一样瞬间收进他的工具车。
```
