## 推荐用法

- 想要更像真实废片：补充“2011 年廉价安卓手机拍摄、自动曝光抽搐、过度锐化、单声道环境音”。
- 想要更像监控录像：补充“固定广角机位、错误时间戳、12fps、没有剪辑、人物从不看镜头”。
- 想要更像五毛特效：补充“塑料材质、绿幕抠像白边、粒子特效模板、动作略微穿模”。
- 生成模型总想拍得太高级时，明确写上“不要电影感，不要精致灯光，不要唯美构图”。
