## 数据海洋

**分类：** `cyber`

**标签：** `数据` `海洋` `代码` `潜水`

**提示词：**

```
A deep-sea diver descends into an ocean made entirely of glowing green code,
binary streams flowing like currents, data packets swimming past like bioluminescent fish,
the pressure increasing as lines of code compress and collapse around the diver,
at the very bottom: a single blinking cursor, alone in the void.
```

**中文版：**

```
一名深海潜水员下潜入一片完全由发光绿色代码构成的海洋，
二进制数据流如洋流般涌动，数据包像生物发光鱼群游过，
随着深度增加，代码行在潜水员周围压缩坍塌，
海底最深处：一个孤独闪烁的光标，在虚空中等待。
```

**推荐工具：** Sora、Kling

**效果描述：** 以第一视角缓缓下潜，周围全是流动的代码与数据光点，沉浸感极强。
